# 최후의 성채: 영주의 결단 — 플레이용 빌드

휴대폰 가로 화면으로 여는 것을 권장합니다. 게임은 브라우저에 자동 저장됩니다.

이 레포에는 게임 실행에 필요한 파일만 있습니다. 개발은 비공개 레포 `hyo7170/castle-defence`에서 하고,
그쪽에서 `npm run build:play`로 만든 결과를 여기에 올립니다. 여기서 직접 고치지 않습니다.

빌드 원본 커밋: `83bc2c4`

## 안드로이드 앱

`main`에 올라갈 때마다 GitHub Actions가 APK를 만들어 Releases의 `latest`에 올립니다.
휴대폰에서 이 레포의 **Releases → 최신 안드로이드 빌드 → last-citadel.apk**를 받아 설치합니다
(처음 한 번 "출처를 알 수 없는 앱 설치"를 허용해야 합니다).

새 빌드는 기존 앱 위에 덮어 설치되며 저장된 게임이 유지됩니다. 서명 키는 시험용 디버그 키
(`.github/android/debug.keystore`)라 스토어 배포에는 쓸 수 없습니다.

그림은 AI 생성 초안이며 상업 배포 전 권리 확인이 필요합니다.
